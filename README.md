# unlegalese
An OpenAI API Prototype

### Project Overview
To help me learn how to build and host apps that leverage LLMs I came up with the idea to use ChatGPT to create human-friendly summaries of legalese documents such as Terms of Service, Privacy Policies, etc.

### Project Goals
- ✅ Learn how to use OpenAI’s API
- ✅ Learn about prompt engineering
- ✅ Expose functionality via backend service using Back4App
- 🚧 Improve UX by leveraging OpenAI API streaming and Back4App LiveQuery
- ✅ Turn app into Google Chrome extension
- ☑️ Learn how to set up Back4App local dev environment
